# Creación e instalación de DC01

## 1. Hipervisor y red virtual

1. Instalación de VMware Workstation Pro (uso personal), versión 25H2.
2. En **Edit → Virtual Network Editor** se creó la red **LAB** (VMnet2):
   - Tipo: Host-only
   - Subred: 192.168.10.0, máscara 255.255.255.0
   - **Use local DHCP service...** desmarcado
   - **Connect a host virtual adapter to this network** marcado

## 2. Asistente de nueva máquina virtual

| Parámetro | Valor final |
|---|---|
| Nombre | DC01 |
| Sistema invitado | Windows Server 2022 |
| Firmware | UEFI |
| Procesadores | 2 vCPU |
| Memoria | 4096 MB |
| Red | Custom: VMnet2 (LAB) |
| Controlador SCSI | LSI Logic SAS |
| Disco | 60 GB, un solo archivo, **sin** preasignar espacio |
| Tarjeta de sonido | Eliminada |
| CD/DVD | ISO de Windows Server 2022 con *Connect at power on* |

### Valores por defecto corregidos

| Valor propuesto por el asistente | Problema | Corrección |
|---|---|---|
| Red "Do not use a network connection" / Host-only (VMnet1) | El asistente no permite elegir VMnet2 en esa pantalla | Se corrigió en *Customize Hardware → Network Adapter → Custom: VMnet2* |
| Disco "Split, Pre-allocated" | Ocupa los 60 GB del host desde el inicio | Se desmarcó *Allocate all disk space now* y se eligió *single file* |
| 4 CPU cores | Satura el host al encender varias VMs | Se redujo a 2 |
| Sound Card | Innecesaria en un servidor | Se eliminó |

## 3. Problema de arranque

Al encender la VM por primera vez apareció `EFI Network... Time out` y no se inició el instalador.

- **Causa:** la ISO no arrancó (aviso "Press any key to boot from CD or DVD..." perdido en UEFI, o ISO no conectada al encender).
- **Solución:** se verificó *Connect at power on* y la ruta de la ISO, se entró al firmware (*VM → Power → Power On to Firmware*) para dar prioridad al CD-ROM y se pulsó una tecla en cuanto apareció el aviso.

Evidencia: `capturas/05-error-arranque-efi.png`.

## 4. Instalación de Windows Server 2022

1. Edición elegida: **Windows Server 2022 Standard Evaluation (Desktop Experience)**. La primera opción de la lista es Server Core (sin interfaz gráfica) y se descartó.
2. Instalación personalizada (*Custom*) sobre el disco de 60 GB.
3. Contraseña de `Administrator` generada en un gestor de contraseñas (nunca documentada aquí).
4. Primer inicio de sesión con *VM → Send Ctrl+Alt+Del*.

## 5. VMware Tools y nombre del equipo

1. *VM → Install VMware Tools*; si la unidad seguía mostrando la ISO de Windows Server, se montó `windows.iso` desde la carpeta de instalación de VMware Workstation.
2. Ejecución de `setup64.exe` (instalación *Typical*) y reinicio.
3. Renombrado del servidor:

```powershell
Rename-Computer -NewName "DC01" -Restart
hostname   # debe devolver DC01
```
